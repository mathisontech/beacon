## 9. Event Declaration & Management

### 9.1 Event Declaration

- EMS can manually declare an event
- Automatic thresholds trigger event declaration and start data storage
- Event triggers adjust suggested map layers (e.g., activate oxygen depletion, heat layers for wildfire)
- Default layers should account for regional disaster proneness

### 9.2 Event Data Storage

- All event-specific input stored in event records (not base map) unless it represents permanent change
- Reports of destruction/damage that affect base map get pushed to base map
- Hazard sightings, status updates, conditions — stored in event records

### 9.3 EMS Event Tools

- Draw zones for team operations and send alerts to drawn areas (polygon-based)
- Mark affected areas
- Designate road areas to keep clear for operational purposes (beyond hazard-based routing)
- Manually mark location of backup units or equipment not tracked on Beacon
- Request help from users near a location via geofenced notification
- Generate secure backup codes for non-Beacon departments/users to temporarily join the effort and appear on the same map
