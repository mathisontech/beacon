🔧 Troubleshooting Connection Issues

🔒 macOS Network Permissions

If you see "Local Network" permission errors:

  1. Go to System Preferences → Security & Privacy → Privacy
  2. Select "Local Network" in the left sidebar
  3. Make sure your browser (Firefox/Chrome/Safari) is checked ✅
  4. Restart your browser and try again

🔥 Firewall Issues

If the connection is blocked:

  1. Go to System Preferences → Security & Privacy → Firewall
  2. Click "Firewall Options"
  3. Make sure Python is allowed or add it to exceptions
  4. Or temporarily disable firewall for testing

🌐 Try Different Browsers

Test with multiple browsers:

  • Safari: Usually has fewer permission issues
  • Chrome: May need permission grants
  • Firefox: Check network settings

🔄 Alternative: Use Different Port

If port 8080 is blocked:

python3 test_server.py --port 8888

Then try: http://localhost:8888
