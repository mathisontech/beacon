# @beacon/base-map

Shared base map + layer management.

## Scope

- `src/views/` — flat-2d, satellite-2d, clay-3d, google-3d
- `src/layers/` — periodic regional, event-triggered, user adjustments, user layers, sensor-driven, live overlays
- `src/overlays/` — live cameras, vehicles, animals, sensors
- `src/controls/` — zoom, view switcher, search

Checkpoint 2 extracts the current `apps/beacon-dev/src/components/map/*` files here.
